1. **C++20**，`Scalar` concept + `ScalarTraits<T>`；**实复差异只存在于 traits 特化，算法层零分支**。
2. **`Matrix` 是哑容器**：扁平行主序存储、`operator[]` 即时派生行指针（不存 `vector<T*>`）、
   逐元素四则 + `Transpose`/`Adjoint`。**其余运算全是 linalg/math 自由函数，不进类**。无缓存层。
3. **函数与算子不进 `Matrix<T>`**：`Scalar` 额外要求乘法交换（`CommutativeScalar`）；
   微分算子走 `LinearOperator{repr, basis, truncation}`（算子 = 基 + 边界条件 + 截断矩阵）。
4. **高维数据靠展平 / 切片**归约为二维线性代数；**`Tensor<T>` 只准是哑容器**
   （存 + 索引 + 形状查询，单线程独立占有），**`TensorView<T>` 是非占有视图**。
   **一切指标收缩 / 乘法 / 求逆仍是自由函数，绝不进这两个类**（原 `matrix.md` §6 第三次订正，现见 `tensor.hpp` 头注释）。
   固定尺寸 `Matrix<T,M,N>` 与 SIMD 推迟。
5. **复数自实现 `Complex<T>`**，不用 `std::complex`；求逆/特征值/SVD 每阶段只实现一种通用简单方法。

## 1. 判据五条（写任何测试前先对一遍）

来源：本仓已发生过的踩坑，按发生次数排序。

1. **分域探针**：模板 bug 必须实/复、`double`/`float` 各实例化一次。
   「double 0 错」掩盖真 bug 已发生 5 次（全在 `complex`）；反向亦然 —— 「编不过」可能只是域不匹配。
2. **判据独立于实现路径**：配独立不变量（`Σσ² = ‖A‖_F²`、两条实现逐元对拍）。
   测排序要喂**明确乱序**的输入。
3. **多方向/多种子判据比归一化后的量**（`derive/seed`），不比原始值。
4. **浮点残渣非零 ⇒ 判量级不判 `== 0`**；用例集必含**病态输入**（`x₁<0` / 尺度悬殊 / 近奇异 / 零阵）。
   **判据可能自身病态**（`acos((tr−1)/2)` 在 θ→0 发散，给 1e-8 假误差）⇒ 换 `atan2` 等价式。
5. **判据函数与批量循环必包 `try`**：异常会 terminate 整个用例（SIGABRT / 退出码 134）。

## 2. 闸门与注入（每条闸门必做两次注入）

- **实例化闸门**：`demo/linalg/smoke.cpp` 用 `EntryTable<T>` 对每个公开入口**取函数指针**（odr-use，强制实例化，刻意不调用）+ `kEntryCount` 计数（漏抄即报警）。
  重载入口用 `static_cast` 消歧；成员重载取不了地址。
- **注入对照**：行为型 + 编译型各一次。收尾流程：`cp` 备份 → 注入 → 跑 → `shasum` 比对 → `grep -r 注入 src/` 查残留 → 复跑全量。
- **盲区自检**：恒等式可能抓不到整体符号翻转（奇次两边同时翻号）。
  例：`Hat³ = −|u|²·Hat` 与 `Vee∘Hat = id` **抓不到 `Hat` 整体翻号** ⇒ 符号必须靠「非对角位置逐位比对 + `Cross` 对拍」钉。
