## 一、图类工具箱

### 1. 甘特图（Gantt / 时空图）

- **何时用**：描述"多任务随时间占用资源"的过程。
- **手画步骤**：
  1. 横轴画**时间轴**（标注刻度），纵轴列**任务/进程号**。
  2. 每个任务占用的时间段画成**横条**，起止对齐刻度。
  3. 标出**到达时刻、开始时刻、完成时刻**三个关键点。
  4. 抢占式算法中，用**分段横条 + 不同底色**表示被抢占。
- **对应考点**：进程调度（FCFS/SJF/RR/优先级/MLFQ）的推演；流水线时空图；总线仲裁。
- **常见画错**：
  - RR 忘记"新到达进程是否插队"；
  - 抢占式与非抢占式混画（抢占要看到达时刻能否打断当前进程）；
  - 时间轴刻度不齐，导致完成时刻读错。

### 2. 架构图 / 数据通路图（Datapath）

- **何时用**：描述硬件部件及其**连接关系与数据流向**。
- **手画步骤**：
  1. 先摆**存储部件**（寄存器、内存、Cache）与**运算部件**（ALU）。
  2. 用**带箭头连线**表示数据通路，箭头旁标**位宽/控制信号**。
  3. 用不同线型区分**数据流 / 控制流**。
  4. 单周期/多周期：标注每个周期经过的部件与路径。
- **对应考点**：CPU 数据通路、控制器（硬布线/微程序）、指令周期、IO 接口。
- **常见画错**：
  - 漏画控制信号（如 MemRead/MemWrite/RegWrite）；
  - 混淆"数据通路"与"控制部件"；
  - 位宽标错（PC 宽度 vs 字长）。

### 3. 状态机图（State Machine）

- **何时用**：描述系统在**有限状态间的迁移**。
- **手画步骤**：
  1. 圆圈 = 状态，初始状态加**入箭头**，终态用双圈。
  2. 有向边 = 迁移，边上标**触发条件**（事件/条件）。
  3. 标注可能引起相同迁移的**多个触发条件**（用逗号或分行）。
- **对应考点**：进程五态迁移（含挂起）、TCP 状态机、Cache 一致性状态。
- **常见画错**：
  - 漏"就绪→运行"的**调度**触发、"运行→就绪"的**时间片到**触发；
  - TCP 状态机漏 CLOSE_WAIT / TIME_WAIT 的来路；
  - 把"事件"和"动作"混写在边上。

### 4. 时序图（Sequence Diagram）

- **何时用**：描述**多个实体间的交互消息顺序**。
- **手画步骤**：
  1. 顶部横向摆**参与者**（垂直线为生命线）。
  2. 按**时间从上到下**画消息箭头，标序号与消息名。
  3. 用不同箭头区分请求/响应、同步/异步。
- **对应考点**：TCP 三次握手/四次挥手、DNS 查询、Cache 访问命中判定、DMA 传输。
- **常见画错**：
  - 三次握手漏"第三次本可携带数据"的细节；
  - 忘记序号/确认号的推进；
  - 时间顺序上下颠倒。

### 5. 地址翻译图（虚拟→物理）

- **何时用**：描述**逻辑地址到物理地址的分段/分页转换**。
- **手画步骤**：
  1. 把逻辑地址**按位拆**（页号 / 页内偏移，或 段号/段内偏移/页号）。
  2. 页号 → **页表查询** → 物理帧号；
  3. 物理帧号 **拼接**页内偏移 → 物理地址。
  4. 多级页表：画出各级页表的**位拆分**与指向关系。
- **对应考点**：页表结构、多级页表、TLB 命中/缺失、缺页中断、段页式。
- **常见画错**：
  - **位拆分算错**（页大小↔偏移位数）；
  - 多级页表的中间级是否有偏移搞混；
  - TLB 与 Cache 的**先后顺序**画反。

### 6. 树 / 堆图（结构推演）

- **何时用**：描述**树形结构的插入/删除/旋转/调整过程**。
- **手画步骤**：
  1. 逐步画出每一步的**结构快照**（不要只画最终态）。
  2. 旋转：标出**最小不平衡子树**的根与旋转方向。
  3. 堆调整：画出**上浮/下沉**的路径。
- **对应考点**：AVL 四种旋转、红黑树插入、B 树/B+ 树插入删除（含分裂/合并）、堆的建立与调整、哈夫曼树构造。
- **常见画错**：
  - B 树**阶数含义搞错**（m 阶 vs 关键字数范围）；
  - 插入后忘记**向上分裂**；
  - 堆调整比较对象错（父 vs 子）。

### 7. 网络拓扑 / 分层转发图

- **何时用**：描述**网络分层、子网划分与路由转发**。
- **手画步骤**：
  1. 画**分层栈**（应用/传输/网络/链路/物理），标注各层数据单元。
  2. 子网划分：画**地址块拆分树**，标出网络号/主机号。
  3. 路由：画出**转发路径**与每跳的查表结果。
- **对应考点**：OSI/TCP-IP 分层、子网划分/CIDR、路由算法、ARP 解析过程、交换机/路由器转发。
- **常见画错**：
  - 子网划分**借位数**与可用主机数算错；
  - 广播地址/网络地址混用；
  - ARP 跨网段（需经网关）漏掉。

## 二、算式手势工具箱（手算模板）

> 计算型知识的核心：**能不能在纸上把数字推对**。以下为通用手算模板，具体数值题见各模块 ③。

| 算式类型 | 核心公式/思路 | 对应考点 |
|---|---|---|
| **Cache 命中率** | 命中率 H = 命中次数 / 总次数；**平均访问时间 EAT = H×Tc + (1-H)×Tm**（多级嵌套） | Cache 映射、多级 Cache |
| **地址位数拆分** | 页/块大小 = 2^(偏移位数)；总位数 = 标记位 + 组/页号位 + 偏移位 | 页表、Cache 映射 |
| **流水线效率** | 加速比 = 非流水时间 / 流水时间；**吞吐率/周期数**（含冒险停顿） | 流水线性能 |
| **调度时间** | 周转 = 完成 − 到达；带权周转 = 周转 / 服务；等待 = 周转 − 服务；响应 = 首次运行 − 到达 | 调度 |
| **子网划分** | 借 n 位 → 子网数 2^n，每子网主机数 2^(剩位) − 2 | 网络层 |
| **吞吐/带宽** | 发送时延 = 数据量 / 带宽；传播时延 = 距离 / 光速；总时延 = 各项之和 | 网络层/链路层 |
| **文件索引** | 直接/一级/二级/三级索引块可寻址的**最大文件大小**逐项相加 | 文件系统 |
| **磁盘访问时间** | 寻道 + 旋转延迟(半圈) + 传输时间 | 磁盘管理 |
| **信号量/PV** | 五步法：数进程 → 定关系(互斥1/同步0/资源N) → 设信号量 → 排 PV 位置 → 查死锁 | 同步互斥 |

**手算纪律**：
1. **先写公式，再代数字**，不要直接口算跳步。
2. **单位统一**（B 与 bit、ms 与 s）。
3. 关键中间量**写在草稿上**，便于回查与检查。
4. 算完**回代验证**（如命中率是否在 [0,1]、时间是否非负）。

## 三、图的"完整覆盖"检查

一个模块该画哪些图，用下表自查（对应 `LEARNING.md` §7.2 完整性清单的"图完整"项）：

| 模块类型 | 必画图 |
|---|---|
| 进程/调度 | 状态机图、甘特图 |
| 存储/虚拟内存 | 地址翻译图、（多级）页表结构图 |
| CPU/指令 | 数据通路图、时序/指令周期图 |
| 流水线 | 时空图（甘特图变体） |
| 文件系统 | 索引结构图、磁盘布局图 |
| 网络 | 分层图、拓扑/转发图、TCP 时序图 |
| 数据结构 | 树/堆结构快照、图遍历示意 |
