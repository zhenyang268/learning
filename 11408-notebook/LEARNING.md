## 一、核心方法论：三层问答（①②③）

一切知识点的学习，都拆成三层，逐层推进：

| 层 | 名称 | 要产出什么 | 回答 |
|---|---|---|---|
| **①** | 机制层（What / How） | 状态机图 / 时序图 / 数据流图 | "它是什么、怎么运作" |
| **②** | 设计层（Why / Where） | 设计动机 + 层级定位 | "它为什么这么设计、站在哪一层" |
| **③** | 验收层（Can-do） | 题型清单 + 模板 + 变式作答 | "怎么考、我能不能在纸上复现" |

**关系（关键，不可误解）**：
- ①② 是**理解的地基**，③ 是**得分的验收**。
- **③ 是最终判据，但不是唯一动作**：③ 通过才算学完；③ 不通过 → 归因 → 回补 ①② 的漏洞。
- 只做 ①②（画图、看动画）会产生**理解幻觉**——能点头，但考场推不出来。**计算型知识必须动笔过 ③。**

## 二、三视角模型（每个子块都要过三关）

对每个知识单元，从三个视角各讲一遍：

| 视角 | 内容 | 产出 |
|---|---|---|
| **课本视角** | 教材定义、特征、标准表述 | "408 原话怎么说" |
| **现实视角** | xv6 / Linux / 真实源码对象 | "真机怎么实现"，及与课本的**边界差异** |
| **应试视角** | 题型、模板、变式、易错 | "怎么考、能否复现" |

**现实视角的边界（重要）**：项目源码只用于**建立直觉、锚定差异**，不作为考核目标。
写现实视角时**必须标注"可用 / 不可用边界"**——即"这段代码帮助理解什么，但 408 不直接考什么"，避免被项目误导（归因维度之一）。

## 三、模块化结构

学习单位是**模块（Module）**，不是零散知识点。每个模块 = **1 个总纲 + N 个有序子块**。

- 总纲（块0）：画**总图**——本模块站在 OS/系统的哪一层，与相邻模块如何衔接。
- 子块：按"**是什么 → 怎么生/建 → 怎么运作 → 怎么协作 → 怎么分配**"的逻辑排序。
- 例：进程模块 = 总纲 + 定义抽象 / 创建控制 / 调度 / 同步互斥 / 资源与 IPC（见 `modules/408/进程.md`）。

**子块的标准格式**（每个子块都长这样）：
```
## 块N 名称  [优先级标签]
### N.1 机制层（①）   → 图 + 说明
### N.2 设计层（②）   → 动机 + 层级定位 + 现实对照（含边界）
### N.3 验收层（③）   → 题型清单 → 模板 → 代表例 → 变式
### N.4 归档          → 落到哪个 ipynb（按 AGENTS.md）
```

## 四、题型驱动机制（③ 的落地）

**核心认知**：408 是**封闭题库**，计算题的"题型"**有限且可穷举**。所以学一个知识点的正确粒度是"**覆盖它的全部题型**"，而不是"做几个例子"。

每个知识点在验收层必须给出一张**题型清单**：

| # | 题型 | 模板要点（通用步骤） | 优先级 |
|---|---|---|---|
| 1 | … | … | ★ |

**每个题型配三样东西**：
1. **代表例**（1 个，讲透）
2. **通用模板**（可迁移的解题步骤，比例子更值钱）
3. **变式**（1 个，换条件验证）

**"学会了"的判据**：给定一个**没见过的变式**，能套模板做出来；而不是"记得那个例子的答案"。

**负向考法也要覆盖**：题目可能给出一段代码/一个设计，问"**哪里错了 / 会不会死锁 / 何时退化**"——这考的是模板的**校验步骤**，纯正例覆盖不到，必须专门练。

## 五、侧重原则（"有侧重"的落地机制）

**侧重不是口号，是可执行字段。** 依据是 408 分值权重：

| 科目 | 分值 | 高权重模块（优先投入） |
|---|---|---|
| 数据结构 | 45 | 树/堆、图、查找/排序、散列表 |
| 计算机组成原理 | 45 | Cache、流水线、浮点运算、指令周期/数据通路 |
| 操作系统 | 35 | 调度计算、PV、页面置换、地址翻译、文件系统索引 |
| 计算机网络 | 25 | 子网划分/CIDR、TCP 拥塞控制、CRC |

**优先级标签（全库统一）**：

| 标签 | 含义 | 处理 |
|---|---|---|
| `★核心` | 高频、分值大、必考 | **优先排入**，必须过 ③ |
| `☆常规` | 常考、需掌握 | 正常推进 |
| `○了解` | 低频、了解即可 | 可快速过，不深追 |

每个**模块**和每个**题型**都要打标签。agent 排学时**先推 ★**。

## 六、agent 引导循环（代替网课）

**开场机制（连贯的第一步）**：每次学习会话开场，agent 先读 `PROGRESS.md`（阶段、模块状态、最近活动、待办）+ 扫描归档 ipynb 的到期复习项（§6B.2），生成**今日面板**（≤ 10 行）：

```
【今日面板】（YYYY-MM-DD）
阶段：真题反查期 · 第 N 周
到期复习：X 项（列出）
上次中断：<模块>/<子块>/<层>
今日建议：主任务 1 个 + 附带 ≤ 2 项
→ 按建议走，还是你指定？
```

**中断点恢复**：用户说"继续"即可——agent 从 PROGRESS.md 的"最近活动"行恢复上下文，不要求用户复述学到哪。这行信息每轮归档时更新，是连贯性的锚。

**引导循环**（接到"学 X 模块"或"继续"后按此推进）：

```
1. 规划：按模块结构拆出子块，标注优先级，给出本轮范围（默认单子块）
2. 讲解：对当前子块，按 ①②③ 三层逐层展开
3. 出题：按题型清单出题（agent 生成，不依赖用户喂题）
4. 判卷：用户作答后，按归因维度诊断
5. 归因 → 回补：不过 → 定位到具体层，回补；通过 → 归档
6. 归档：按 AGENTS.md 写入对应 ipynb，报告结果；更新 PROGRESS.md
7. 推进：进入下一子块，或按用户指令跳转/复习
```

**效率纪律（连贯 ≠ 拖长）**：
- **一轮一闭环**：讲解 → 出题 → 判卷 → 归档在同一轮完成，不跨天挂着——挂两天就是假性理解滋生。
- **讲解量与错题密度成正比**：连续答对的题型快速过模板，错题处才展开 ①② 回补。不平均用力。
- **计时反馈**：限时作答记录实际用时，面板跟踪**限时正确率**趋势（冲刺期唯一有意义的指标）。
- **纸质刷题是冲刺期主路径**：流程见 §6B.3；刷题轮次不受本循环约束，按"做完一套 → 拍照 → 判卷 → 反查"走。

**归因维度（判卷必用）**：`概念不清 / 计算失误 / 没记住 / 审题错 / 项目误导 / 存疑待核`。

**粒度纪律**：默认**单子块**推进。用户说"继续"才进入下一块；用户说"跳过/复习某块"则按指令。**不要一次性讲完整个模块**（防止信息过载与假性理解）。

**出题纪律**：
- agent 负责规划与出题，**效率优先**，不要求用户喂题。
- 用户的习题册仅作**题型同源锚定**：agent 出的题与用户册子里的题型对齐，防止 AI 自由发挥导致方向偏移。
- 出题难度默认对齐 **408 真题**；可另设"挑战档"（见 §八）。
- **限时作答**：验收出题默认注明**建议用时**（对齐真题：单选约 2 分钟、计算大题约 15–20 分钟）；用户可明确说不限时。**作答超过建议用时，即使全对也按"部分通过"处理**——考场拼的是限时正确率。

## 6A、冲刺期日历（距初试约 10 周）

> **锚点（用户确认）：2026 年 12 月下旬初试**（通常为 12 月倒数第二个周末，具体以教育部公告为准），自 2026-10-11 起算约 10 周。
> **三阶段结构（基础/强化/冲刺）不适用**——没有"从头模块滚动"的时间了。直接进入冲刺节奏：**真题驱动，以战代练**。

| 阶段 | 时间窗 | 目标 | 数学/408 | 政治 | 英语 | 模考频率 |
|---|---|---|---|---|---|---|
| **真题反查期** | 现在 → ≈11 月中（约 5 周） | 成套真题 + 错题定位回补：错题 → 定位模块/子块 → 只补 ①② 漏洞 → 过 ③ → 归档 | 真题套卷 + ★核心模块补漏 | **立即启动**：马原重理解，毛中特/新思想/史纲/思法直接刷选择题 | 真题套卷 + **作文模板本周建** | 每周 1 套 |
| **全真模考期** | ≈11 月中 → ≈12 月初（约 3 周） | 限时全真模考 + 错题**重做** | 套卷限时 + 错题重做 | 选择题二刷 + 分析题模板背诵 | 作文仿写 + 套卷 | 每周 1–2 套 |

**冲刺期纪律**（10 周内全程生效，优先级高于其他节奏条款）：
- **以战代练**：不做"从头学"的模块滚动。新知识只从**真题错题反查**进入：错题 → 定位 → 回补 ①② → 过 ③ → 归档。没在真题里出现的偏门子块，放弃。
- **遗忘曲线压缩**：只用 `R1`(1天) / `R2`(3天) / `R3`(7天) 三档，`R4`/`R5` 弃用（10 周内走不到）；**到期复习不许顺延**（§6B.2 允许顺延的规则在冲刺期失效）。
- **政治不能等**：没有"政治后启动"的余地。选择题立即开始；分析题模板 11 月底前背完第一轮。
- **英语作文提前**：模板本周建立（不等最后两周），此后每周仿写一篇保持手感。
- **真题优先级**：近 10 年真题 > 更早年份 > 模拟卷（模拟卷只在真题刷完且时间富余时用）。
- 若日后考试改期至完整周期（≥ 12 个月），恢复"基础:强化:冲刺 ≈ 5:3:2"三阶段结构（此为通用备份，不在此展开）。

## 6B、判卷与遗忘管理

### 6B.1 判卷边界（什么算"通过"）

- **客观题（选择/填空）**：以**题面**为唯一事实源。答案冲突时，**agent 必须写明依据**（知识来自 408 大纲、王道/真题等主流辅导书的共识表述，还是自己的推断）；无法判定的题归"存疑待核"，**不得强行裁定**，并如实计入错题归因"存疑待核"维度。**用户答对但用了错误路径也要标出**（错误路径 ≠ 正确答案，考场换个数就露馅）。
- **大题（计算/综合）**：按**步骤给分**，不只看最终答案。计算根节点错了但步骤正确、思路对 → 记"计算失误"归因（重算一遍即可），不当概念错误处理。
- **归因维度**（§六）：`概念不清 / 计算失误 / 没记住 / 审题错 / 项目误导 / 存疑待核`——最后一维是兜底（答案依据不明时用），不硬贴标签。

### 6B.2 遗忘管理（遗忘曲线表）

归档时（AGENTS.md §五）在 cell 末尾追加一行：

```markdown
- **复习计划**：{{复习标记}} @ {{日期}}
```

标记与周期：`{{复习标记}}` ∈ {`R1`(1天) / `R2`(3天) / `R3`(7天) / `R4`(15天) / `R5`(30天)}，到期重做（变式优先），通过则标注通过并升档，未通过则同档重排。**当前冲刺期（§6A）只启用 R1/R2/R3，R4/R5 冻结**。agent 接到"今天复习什么"时，扫描归档 cells 的复习计划行，**到期项**列表输出。
- 到期复习项**不占新知识预算**：当天任务 = 新子块（默认 1 个）+ 到期复习（全部）。
- 复习项顺延规则：完整周期内**不必须全清**、可顺延（学习目的是掌握，不是清表）；**冲刺期（§6A）内到期复习不许顺延**。

### 6B.3 纸质刷题与模考纪律（冲刺期主路径）

**介质**：纸质真题 + 模拟卷（用户自备），agent 负责判卷、归因、反查——各干各擅长的事。

**提交方式（拍照三律）**：
1. **一页一图，拍正拍满**：整页入镜、不切角、光线均匀；多页分多张，按顺序发。
2. **发图配一行元信息**：卷名年份 + 题号范围 + 限时与否（未计时就写"未计时"）。例：`2018 数一 · 1–10 题 · 限时 30 分钟`。
3. **可选**：点名没把握的题号——判卷时这些题优先做**路径检查**（答案对但过程错也要标）。

**判卷流程**：读图 → 逐题对答案（**答案依据不明标"存疑待核"，不硬裁**）→ 区分 步骤错 / 概念错 / 计算错 → 按归因维度归类 → 生成本轮报告（逐题得分、归因分布、易错点）→ **错题当日归档 + 更新 PROGRESS.md**。字迹潦草认不出的地方直接问，**不猜**。

**反查闭环（以战代练的执行路径）**：模考/刷题错题 → 定位 `modules/` 里的子块 → 只补该子块的 ①② → 过 ③（换变式）→ 归档。错题在哪，课就补在哪。

**模考 = 限时整套**，判卷后必须生成**模考报告**（追加到 Misc/临时问题.ipynb，标题加 [模考] 前缀），含：逐题得分、耗时、错误归因分布、限时压力下的错误聚类（"平时会、模考错"的题单独列出）。报告里的错题当日归档，不积压。

# PROGRESS.md — 11408 学习进度仪表盘

## 七、完整性与归档

### 7.1 学习单元归档格式

沿用 `AGENTS.md` 第五节的标准 cell 格式（**只追加，不修改**）：

### 7.2 完整性自检清单（每完成一个模块必查）

| 维度 | 检查项 |
|---|---|
| **子块完整** | 模块的子块是否全部展开？有无遗漏子块？ |
| **三层完整** | 每个子块是否都有 ①②③？有没有只讲机制、没给题型的？ |
| **三视角完整** | 每个子块是否都过了课本 / 现实 / 应试？现实视角是否标了边界？ |
| **题型完整** | 该知识点的题型清单是否穷举？每类是否配了代表例+模板+变式？ |
| **图完整** | 该模块该画的图（甘特图、状态机、架构图…）是否都画了？（见 TOOLKIT.md） |
| **侧重落实** | 优先级标签是否打了？★ 是否优先推进？ |
| **归档完整** | 对话是否已按 AGENTS.md 落盘？ |
| **遗忘字段完整** | 归档 cell 是否都带了复习计划行（档位 @ 日期）？ |
| **仪表盘同步** | PROGRESS.md 对应行是否已更新？ |

**任一维度不达标 → 不得标记本模块"学完"。**

## 九、禁止事项

- ❌ 不得只讲机制（①）就宣布"学完"——**没过 ③ 不算学完**。
- ❌ 不得用"几个例子"冒充"题型覆盖"——必须**列题型清单**。

- ❌ 不得让用户喂题作为主流程——agent 负责出题，习题册只作锚定。

- ❌ 不得编造未提供的内容——缺失写「待补充」。
- ❌ 不得偏离应试主线——项目/可视化服务于理解，**分数靠真题与 ③**。
